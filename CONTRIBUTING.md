# Mitwirken

1. Forke das Repository.
2. Erstelle einen Feature-Branch.
3. Baue das Projekt lokal mit `./gradlew build` bzw. `gradlew.bat build`.
4. Öffne einen Pull Request mit einer kurzen Beschreibung der Änderung.

Bitte ändere die Einsatzprüfung nicht so, dass Einsätze von 0 oder weniger akzeptiert werden.
